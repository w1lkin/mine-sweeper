# 扫雷 5 项优化 · 设计文档

- 日期：2026-07-29
- 项目：`mine-sweeper/`（单文件 `index.html` + `style.css` + `game.js`）
- 目标：在保持现有玩法、纯逻辑层可测试、零依赖的前提下，新增 5 项摸鱼向优化。

## 原则

- 纯逻辑层（`game.js` 前半段，`typeof module !== 'undefined'` 导出部分）继续零 DOM、可在 Node 测试。
- 所有新功能默认可关 / 可逆，不影响现有计分与分享卡。
- 不引入任何外部依赖、框架或构建工具。

## 控件布局（新增工具栏）

在「难度选择」与「棋盘」之间新增一条紧凑工具栏 `controls`，放三个新控件，宽度适配 480px：

- `自动标雷` 开关（toggle）
- `⏸ 暂停` 按钮
- `🙈 沉浸` 按钮

原 `重开 / 分享` 仍保留在下方 `actions` 区。

---

## 1. 自动标雷（可选，默认 **开**）

### 逻辑
新增纯函数 `autoFlag(board)`，遍历所有「已翻开的数字格」，对 8 邻域统计：
- `flagged`：已插旗的邻格数
- `hidden`：未翻开且未插旗的邻格数

规则（仅一种确定性推导，**绝不猜测**）：
- 若 `flagged + hidden === 该格数字` → 剩余 `hidden` 邻格**必为雷** → 自动 `toggleFlag` 加旗。

该规则在经典扫雷中逻辑完备，不会出现误标。

### 集成
- 每次 `reveal` / `toggleFlag` 后，若开关开启则跑一遍 `autoFlag` 再 `render`。
- 开关状态用 `localStorage` 记忆（key 如 `minesweeper_autoflag`）。
- 仅作辅助，不改动分数、记录、计时等任何逻辑。

---

## 2. 暂停（点外暂停 / 点牌面恢复）

### 状态
新增 `paused` 布尔状态。暂停时：
- 停表：`clearInterval(timerId)`，冻结计时。
- 在 `#board` 上叠加一层「暂停遮罩」，遮挡视线并拦截点击（显示「已暂停」文案）。

### 交互
- **点棋盘外 → 自动暂停**：`document` 点击监听。
  - 目标在 `#board` 内 → 忽略（不暂停）。
  - 目标是控件按钮（难度 / 重开 / 分享 / 自动标雷开关 / 沉浸按钮）→ **放行，不暂停**（否则点重开会变成暂停）。
  - 其余空白区域点击 → 暂停。
- **单击牌面 → 取消暂停**：暂停遮罩覆盖在棋盘之上，点击遮罩即 `paused = false` 并恢复计时（遮罩消失，棋盘可见可操作）。
- 游戏结束（`finished === true`）时不响应暂停 / 恢复。

### 与计时关系
暂停期间 `timer` 值不变；恢复后用原 `startTimer` 逻辑继续累加。

## 3. 横向滚动条常驻

- `.board` 已为 `overflow-x:auto`。新增自定义滚动条样式，移动端也常显：
  - WebKit：`::-webkit-scrollbar` 固定高度 / 宽度；`::-webkit-scrollbar-thumb` 中性灰圆角；`::-webkit-scrollbar-track` 浅灰。
  - Firefox：`scrollbar-width: thin; scrollbar-color: <thumb> <track>`。
- 高级 30×16 在移动端竖向也可能超出视口，顺便开放 `overflow-y:auto`，双向均有常驻滚动条。
- 仅在棋盘实际溢出时显示滚动条（内容放得下时不显示），符合原生行为。

---

## 4. 浅色 + 网格线（轻量 Excel 风）

- 丢弃绿色主题，改为办公白：
  - 页面底 `#f3f3f3`，面板白 `#fff`，主文字 `#222`，次级文字 `#666`。
  - 强调色保留一抹低饱和蓝/灰，避免刺眼。
- 棋盘「单元格」观感：
  - 去掉 `gap`，改为每格 `1px solid #d0d0d0` 细灰边框，整体呈现连续表格网格。
  - 未翻开格：白底；已翻开格：`#fafafa` 或白底 + 边框。
  - 数字配色保留但调深以适配白底（蓝 / 绿 / 红 / 紫等）。
  - 雷（`💣`）、旗（`🚩`）样式保留。
- 仍是明显扫雷界面，仅视觉干净、像电子表格。

---

## 5. 沉浸式扫雷（按钮切换进入 / 退出）

- `body.immersive` 类控制显隐：
  - **隐藏**：顶部标题、难度选择、分享/重开按钮、最近战绩。
  - **保留**：极简顶栏 = `💣/⏱` 状态栏 + `😎 退出沉浸` 按钮（即原沉浸按钮切换文案，保证可退出）。
  - 棋盘本体始终显示。
- 暂停遮罩在沉浸态同样可用：点外（棋盘外空白）→ 暂停；点牌面 → 恢复。沉浸与暂停互不冲突。
- 开关状态用 `localStorage` 记忆（可选，便于下次直接沉浸）。

---

## 数据流 / 状态变量

浏览器层新增状态：
- `autoFlagOn`（布尔，默认 `true`，持久化）
- `paused`（布尔，默认 `false`）
- 沉浸态通过 `document.body.classList.toggle('immersive')` 表达（持久化可选）

纯逻辑层新增导出：`autoFlag(board)`。

---

## 测试

- 现有 `node --test tests/game.test.js tests/records.test.js` 保持通过。
- 为 `autoFlag` 补单测：构造已知必雷场景（如 1-2-1 缺口、单格数字等于 hidden 数等），断言对应 hidden 邻格被加旗、且不会误标安全格。
- 暂停 / 沉浸 / 滚动条 / 配色均为纯 UI 行为，沿用现有项目约定（无 DOM 自动化测试先例），靠浏览器手测验证，不强行新增 DOM 测试框架。

## 不做的范围（YAGNI）

- 不实现「全套 Excel 皮肤」（标题栏 / 功能区 / 列字母行号）——本期仅浅色 + 网格线。
- 不实现悬浮小窗 / 可拖动窗口。
- 不引入猜测型自动标雷（如概率提示、多格联合推理）。
- 不改分享卡生成逻辑（除配色跟随浅色主题外，分享卡本身保持现有黄绿色调或按需微调，不影响功能）。
